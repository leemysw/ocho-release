# ocho runtime releases

Prebuilt binaries of **ocho**, a personal agent runtime. Source code is not published; the binaries are licensed under [Apache-2.0](LICENSE).

ocho is bundled with [yovoice](https://github.com/leemysw/yovoice) as its built-in AI assistant runtime.

| Platform | Asset |
| --- | --- |
| macOS · Apple Silicon | `ocho-<version>-darwin-arm64.tar.gz` |
| Windows · x64 | `ocho-<version>-windows-amd64.zip` |
| Linux · x64 | `ocho-<version>-linux-amd64.tar.gz` |

Each archive contains the `ocho` executable and `LICENSE.txt`. Checksums are listed in `SHA256SUMS` on every release.
